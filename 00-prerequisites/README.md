# 00 - Prerequisites

Goal: verify your host is ready and install required tooling before touching poky.

- Read `system-requirements.md` and confirm your OS, CPU, RAM, and disk meet Yocto guidance.
- Install base packages from `tools-installation.md` (use the commands matching your distro).
- Set up proxies/mirrors if needed; note them in `notes/learning-journal.md`.
- Pick a dedicated build directory outside this repo (e.g., `~/yocto-build`).
